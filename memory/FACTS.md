# Verified Facts

- CMS publishes Medicare Claims Synthetic Public Use Files (SynPUFs) for learning/development while protecting beneficiary privacy.
- CMS states DE-SynPUF contains Beneficiary Summary, Inpatient Claims, Outpatient Claims, Carrier Claims, and Prescription Drug Events.
- CMS states the files are synthetic and have limited inferential value for conclusions about Medicare beneficiaries.
- CMS provides DE-SynPUF as free downloads and publishes a user document/codebook.
- Core project must use only synthetic/public-use data and zero-cost local infrastructure.
